## 🧠 The New Architecture

AutoReturn has moved away from traditional monolithic design to a **Decoupled Orchestrator-Agent Architecture**. This design (invented for maximum responsiveness) separates data fetching from AI intelligence.

### 🧩 Core Components

1. **The Orchestrator**: The central brain that routes natural language commands and manages the lifecycle of all agents.
2. **Intelligent Agents**: Specialized workers (GmailAgent, SlackAgent) that execute tasks concurrently using `asyncio`.
3. **Progressive Loading**: A revolutionary UI approach where messages are fetched instantly (<1s) and AI summaries are "layered" on top in the background using a non-blocking queue.

## ✨ Key Features

### 📨 Unified Inbox

* **Gmail & Slack Integration**: Real-time sync of emails and chat messages.
* **Instant Load**: Messages appear immediately after fetching; no waiting for AI.
* **Unified Search**: Search across both platforms with advanced filters.

### 🤖 AI Intelligence & Automation

* **Smart Summaries**: Automatic 1-2 sentence summaries generated by `kimi-k2.5` or `Llama3` using a parallelized non-blocking queue (up to 5 concurrent jobs).
* **AI Task Classification**: Every message is automatically classified into one of 5 actionable categories:
  * 📎 **File Attachment Required** — sender is requesting a document
  * ✍️ **Draft Generation** — needs a detailed, composed reply
  * ⚡ **Auto Reply** — transactional message, simple acknowledgement
  * 💬 **Simple Reply Required** — quick response or confirmation expected
  * ℹ️ **Informational** — no action needed, read-and-archive
* **4-Part Priority Algorithm**: A high-speed hybrid algorithm integrating:
  * **Algorithm 02 (Keyword Engine)**: scans for Direct Urgency, Time Pressure, and Action Calls with spaCy-powered negation detection.
  * **Algorithm 03 (Deadline Engine)**: Regex-based extraction of absolute (dates) and relative (today, tomorrow) deadlines with urgency bonuses.
  * **Algorithm 04 (Sender Engine)**: Tone-aware importance scoring using a configurable User Priority List.
* **Dynamic Rules Editor**: A fully functional Priority Rules editor in Settings allowing live updates to the AI's priority weights without restarts.

### 📅 Calendar & Event Extraction

* **Hybrid Detection**: Combines keyword/regex matching with LLM fallback for robust event detection.
* **Event Types**: Detects meetings, deadlines, appointments, and reminders from both Gmail and Slack messages.
* **ICS Export**: Extracted events can be reviewed and exported to `.ics` format for any calendar app.
* **Confidence Scoring**: Each detected event includes a confidence score for accuracy transparency.

### 🎭 Advanced Tone Detection

* **80% Accuracy**: Hybrid deterministic algorithm with lexicon + embedding fallback.
* **Real-time Analysis**: Sub-5ms processing for instant tone detection.
* **Smart Tone Suggestions**: Automatic tone recommendations based on message content and platform (Gmail vs Slack).

## � Technical Highlights

### 🎯 Tone Detection Engine

* **Hybrid Algorithm**: Combines 60+ word lexicon with spaCy embedding similarity

* **9-Stage Pipeline**: Preprocessing → Tokenization → Scoring → Normalization → Classification
* **Context Awareness**: Handles negation, intensifiers, and combined slurs
* **Performance**: <5ms processing time with 80% accuracy on real-world messages

### 🧠 Learning & Adaptation

* **User Preference Storage**: JSON-based tone profiles with sender/domain preferences

* **Real-time Learning**: Learns from manual tone selections in Gmail/Slack dialogs
* **Effectiveness Tracking**: Monitors tone quality and adapts recommendations
* **Auto-tone Suggestions**: Intelligent tone recommendations based on tone detection

### 🎨 UI/UX Integration

* **ToneDetectionDisplay Widget**: Shows detected tone with confidence indicators

* **ToneSelector Component**: Manual override with "Detected: [Tone]" display
* **Real-time Updates**: Immediate analysis as users compose messages
* **Platform Awareness**: Different defaults for Gmail vs Slack

## �🛠️ Setup & Installation

### 1. Prerequisites

* **Python 3.12+**
* **Ollama** (Download from [ollama.ai](https://ollama.ai))

### 2. Quick Start

```bash
# Clone the repository
git clone <repo-url>
cd AutoReturn

# Install dependencies
pip install -r requirements.txt

# Install spaCy model used for semantic analysis
python -m spacy download en_core_web_md

# Pull the required AI model
ollama pull kimi-k2.5:cloud

# Authenticate with Ollama Cloud (required for cloud models)
ollama signin

# Launch the app
./run.sh
```

The configuration is handled via the UI settings menu.

* **Slack**: Requires a User Token (`xoxp-...`) with `history` and `read` scopes.
