## 🧠 The New Architecture
AutoReturn has moved away from traditional monolithic design to a **Decoupled Orchestrator-Agent Architecture**. This design (invented for maximum responsiveness) separates data fetching from AI intelligence.

### 🧩 Core Components
1.  **The Orchestrator**: The central brain that routes natural language commands and manages the lifecycle of all agents.
2.  **Intelligent Agents**: Specialized workers (GmailAgent, SlackAgent) that execute tasks concurrently using `asyncio`.
3.  **Progressive Loading**: A revolutionary UI approach where messages are fetched instantly (<1s) and AI summaries are "layered" on top in the background using a non-blocking queue.

## ✨ Key Features

### 📨 Unified Inbox
*   **Gmail & Slack Integration**: Real-time sync of emails and chat messages.
*   **Instant Load**: Messages appear immediately after fetching; no waiting for AI.
*   **Unified Search**: Search across both platforms with advanced filters.

### 🤖 Local AI Intelligence
*   **Smart Summaries**: Automatic 1-2 sentence summaries generated by `kimi-k2.5` or `Llama3`.
*   **Task Extraction**: AI identifies if a message needs a "Smart Draft", "Auto Reply", or is "Informational".
*   **Keyword Scoring**: High-speed hybrid priority detection for urgent messages.

## 🛠️ Setup & Installation

### 1. Prerequisites
*   **Python 3.10+**
*   **Ollama** (Download from [ollama.ai](https://ollama.ai))

### 2. Quick Start
```bash
# Clone the repository
git clone <repo-url>
cd AutoReturn

# Install dependencies
pip install -r requirement.txt

# Pull the required AI model
ollama pull kimi-k2.5:cloud

# Authenticate with Ollama Cloud (required for cloud models)
ollama signin

# Launch the app
./run.sh
```

## ⚙️ Configuration
The configuration is handled via the UI settings menu. 
*   **Gmail**: Requires `client_secret.json` from Google Cloud Console.
*   **Slack**: Requires a User Token (`xoxp-...`) with `history` and `read` scopes.
